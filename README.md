## Getting Started

### Prerequisites

- Git
- Node.js 18+

### Setup and Run

```bash
git clone https://github.com/ENZOMOTIVE/D-JobFinder.git
cd D-JobFinder
```

```bash
cd Server
npm install
```

```bash
cd admin-interface
npm install
npm start
```

```bash
cd org-interface
npm install
npm start
```
